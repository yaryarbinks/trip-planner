# trip-planner

Public Vietnam trip planner for October–November 2026.

## Privacy rule
This repository is public. Keep only trip-planning information here. Do **not** add:
- traveler names or personal identifiers
- booking confirmation/reference numbers
- passport or visa numbers
- phone numbers, email addresses, account data
- payment/card details
- private calendar data unrelated to the trip

The site may contain public trip information such as cities, dates, hotel/venue names, festival schedules, public map locations, activities, and approximate budget figures.
